AI Coding Agent

An autonomous coding assistant built in Python that uses an LLM with tool calling to explore a codebase, edit files, and execute scripts to diagnose and fix bugs.

Features:

Tool Calling: Inspects directory structures, reads files, writes code, and executes Python scripts.

Autonomous Loop: Reasons through errors and iterates on code until tasks are complete.

Pluggable Models: Integrates via OpenRouter to test different LLM backends.
